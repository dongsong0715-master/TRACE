## 浏览器实际联调

使用 Codex 内置浏览器访问 http://localhost:5173，操作本机合成测试账号，无外部账户和真实学生数据。

1. 注册学生账号，跳转登录并显示创建成功。
2. 使用错误密码，显示“用户名或密码不正确”。
3. 正确登录，进入真实工作台。
4. 保存昵称、本科、Python方向和北京/天津；界面返回成功，工作台展示已保存内容。
5. 刷新资料页面，会话恢复且城市等内容仍保留。
6. 退出后直接访问 /profile，回到登录页。
7. 登录页密码可显示/隐藏，390px CSS宽度没有横向溢出，表单与登录按钮可达。
8. 风格预览可切换候选岗位、收藏/取消、记录模拟投递并关闭说明弹窗；这些操作不调用业务API，刷新后清空。
9. 风格预览在390px CSS宽度没有横向溢出，收藏按钮可通过滚动操作。

上述操作已在本机浏览器验证。截图与设计对照报告不随仓库交付，团队可启动应用查看当前页面，并使用本记录了解已覆盖的验证范围。
